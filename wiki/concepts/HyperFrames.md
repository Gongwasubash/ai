# HyperFrames

Free, open-source toolkit that lets Claude generate motion graphics using HTML/CSS animations.

## How It Works
1. Claude builds an HTML webpage with animations
2. Screen records the webpage
3. Converts recording to video
4. Imports into Premiere Pro timeline

## Why HTML > Video Gen Models
- **Cleaner** — Precise control over every element
- **Faster** — No waiting for AI video generation
- **Free** — Open-source, no API costs
- **Customizable** — Any style, any animation

## Use Cases
- Animated text overlays
- Planet/Earth graphics
- Transition effects
- Lower thirds
- Any motion graphic
