# Premiere Pro MCP

Model Context Protocol (MCP) bridge that lets Claude control Adobe Premiere Pro directly.

## Capabilities
- Import footage
- Cut timeline
- Add transitions
- Apply effects
- Keyframe animations
- Audio presets

## Supported Software
- Adobe Premiere Pro
- DaVinci Resolve Studio (paid version)
- Final Cut Pro

## How It Works
Claude sends commands via MCP → Premiere Pro executes actions → Timeline updated
