# Generative UI

An AI capability where agents build and render live, working applications directly inside the chat interface — not code for an app, not a screenshot, but the actual running thing in the conversation.

## How It Works

1. User issues a slash command with a natural language description
2. Agent builds the app (HTML/CSS/JS or equivalent)
3. App renders as an interactive artifact inline in the chat
4. User can interact with sliders, buttons, charts, animations — all live

## Examples

- **Loan Calculator** — sliders update a live chart in real time
- **Sorting Algorithm Race** — animated visualization with audio
- **Project Code Graph** — interactive node graph of a codebase
- **YouTube Galaxy** — data visualization with physics animation

## Significance

Represents the shift from "AI writes code you copy-paste elsewhere" to "AI builds and runs apps where you're already chatting." Reduces the gap between idea and working prototype to seconds.
