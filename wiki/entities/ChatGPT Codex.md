# ChatGPT Codex

OpenAI's coding agent tool. Used as the LLM agent that reads sources, maintains the wiki, and answers queries. Free tier is sufficient for basic use.

## Role in Second Brain

- Opens the vault folder as a project
- Processes raw files on command ("process the raw file")
- Answers questions against the wiki ("wiki query: What is...?")
- Maintains cross-references and updates pages
