# Chat Cut

First AI video editor that lives inside Claude Code. Edit videos with natural language prompts, get a fully editable timeline, create motion graphics, generate AI b-roll, and save your workflow as a reusable skill.

## Features

- Natural language video editing ("Cut the dead air", "Tighten up the intro")
- Fully editable timeline (manual adjustments still possible)
- Motion graphics generation
- AI b-roll footage generation
- Save workflow as skill for future videos
