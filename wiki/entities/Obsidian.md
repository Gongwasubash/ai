# Obsidian

Offline markdown-based notes app. Used as the "IDE" for the second brain — the LLM makes edits, the user browses results in real time via graph view, backlinks, and page content.

## Role in Second Brain

- Vault structure maps directly to the wiki architecture (raw/, wiki/)
- Graph view shows cross-references between pages
- Attachment folder set to `raw/assets/` for local image storage
- Plugins mentioned: Obsidian Web Clipper, Dataview, Marp
