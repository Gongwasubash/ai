# Antigravity

AI platform that ships generative UI capabilities — agents can build live working apps and render them directly inside the chat interface. Not just code output or screenshots, but actual running applications inline.

## Key Feature: Generative UI

- Slash command triggers the agent to build and render a live app inside the chat
- Powered by Gemini 3.7 Flash for fast generation
- Each app built from a single natural language prompt
- Renders as an interactive artifact within the conversation
