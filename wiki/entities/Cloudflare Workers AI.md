# Cloudflare Workers AI

Serverless AI platform running on Cloudflare's edge network. Offers text-to-image (Flux model), LLM inference, and other AI workloads with a generous free tier (10,000 credits/day). Accessible via API and connectable to AI assistants like [[Claude]] through [[MCP (Model Context Protocol)|MCP]] connectors.

## Key Details

- **Free tier:** 10,000 credits/day for Workers AI
- **Flux model:** text-to-image generation model available on the platform
- **API access:** REST API with bearer token authentication
- **MCP integration:** can be wired as an MCP server in Claude settings for direct image generation
