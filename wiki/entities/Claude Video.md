# Claude Video

Free tool that teaches Claude any skill by feeding it YouTube tutorials. Grabs transcript AND visuals for full context (not just text guessing), then creates a reusable workflow saved as a skill.

## How It Works

1. Drop in a YouTube tutorial link
2. Tool grabs transcript + video frames
3. Claude gets full visual + text context
4. Ask Claude to create a workflow
5. Save as reusable skill
