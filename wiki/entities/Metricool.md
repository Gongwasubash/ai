# Metricool

Social media scheduler with API access. Used by [[Vaibhav Sisinty]] not for scheduling but as a data harvesting layer for AI agents.

## How It's Used

- Connects Instagram, LinkedIn, TikTok, YouTube, Facebook, Twitter
- Harvests all social metrics into one platform
- API key given to [[Hermes Agent]] or other agents
- Agent pulls data daily, generates 7-day social media reports
- ~$100/month — expensive, designed for multi-account managers

## Why It Matters

Demonstrates the "software for my agent" pattern — SaaS tools used purely as data layers for AI, not for their intended UI.
