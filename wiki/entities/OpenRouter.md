# OpenRouter

Unified LLM API service that provides pay-as-you-go access to hundreds of AI models from OpenAI, Anthropic, Google, and others. Recommended model provider for [[Hermes Agent]].

## Key Points

- Single API key for access to hundreds of models
- Pay-as-you-go billing (no monthly commitment)
- Supports Claude, GPT, Gemini, open-source models
- Add credits ($5-10 recommended to start)
- Generate API keys at [openrouter.ai](https://openrouter.ai/)

## Usage with Hermes

1. Create OpenRouter account
2. Add credits to wallet
3. Generate API key
4. Paste key in Hermes model provider settings
5. Select preferred model (e.g., Claude Sonnet)
