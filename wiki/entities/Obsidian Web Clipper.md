# Obsidian Web Clipper

Browser extension by Obsidian. Clips web articles and YouTube video transcripts directly into an Obsidian vault as markdown files.

## Key Features

- Converts web pages to markdown
- Can pull YouTube video transcripts
- Sends clipped content to a configured vault folder
- Useful for quickly populating the `raw/` directory
