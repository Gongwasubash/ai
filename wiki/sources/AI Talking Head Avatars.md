# AI Talking Head Avatars — Google Flow (Case Studio)

**Source:** YouTube video by [[Case Studio]], 2026-08-07
**URL:** https://www.youtube.com/watch?v=zKPxv49tMRU

## Summary

Full workflow for a [[Consistent AI Character]] that keeps the same face, voice, and behavior across videos: structured character-prompt generator → ChatGPT image → [[Google Flow]] character (face + custom accent voice lock) → 10-second / 32-word dialogue clips with bracket action cues → CapCut assembly.

## Key Takeaways

### Character Definition
- Prompt-generator form: gender, age, ethnicity, body, hair, eyes, hyperrealistic style, personality, role, expression, outfit + background scene (preset or Pinterest reference upload — environment only, not subject)
- Dimensions by platform: 9:16 reels/TikTok, 16:9 YouTube
- ChatGPT produced the cleanest image results for this use case

### Face + Voice Lock in [[Google Flow]]
- Upload image → name character → voice presets or custom voice from a text description ("a lady with a British accent" — any accent works)
- Optional personality line ("warm and conversational") shapes delivery

### Clip Generation Loop
- Agent mode OFF; tag scene image with @, tag character as subject, reference voice in audio section
- Dialogue ≤32 words per clip (Omni 10s cap); 16:9, 10s, one clip at a time
- Reuse-prompt arrow per line of script until the full script is covered
- **Action cues in brackets** (`[looks at her body]`) produce acted expressions, not just lip-sync

### Assembly
- CapCut: order clips, trim dead space, done

### Relevance
- Directly applicable to Nepali-voiceover explainer formats (Mahispal-style videos): a recurring presenter character with locked voice
