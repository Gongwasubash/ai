# Viral 3D Motion Graphics Recreation — Omni 1.1 Flash (Case Studio)

**Source:** YouTube video by [[Case Studio]], 2026-09-02
**URL:** https://www.youtube.com/watch?v=6Tth927NQWc

## Summary

No-After-Effects pipeline for cloning viral 3D motion graphics: Claude scene-by-scene breakdown → [[Google Flow]] Omni 1.1 Flash 10s clips (sound-design line + no-VO negative prompt) → ElevenLabs voiceover (10k free credits) → CapCut assembly — plus [[Viral Style Repurposing]] the same visual DNA onto your own narration.

## Key Takeaways

### The Pipeline
1. **Break down with Claude:** upload reference reel, prompt for per-shot prompts (camera, action, lighting, environment, expressions, composition, transitions, exact on-screen text)
2. **Generate in Flow:** video mode, 9:16, Omni 1.1 Flash, one clip at a time; append "Use professional sound effect design." + negative prompt "Do not include voice over, speech, or background music"; split ~30s refs into 3×10s generations; regenerate slips (baked-in VO happens — mute it in edit if visuals are good)
3. **Voiceover:** Claude extracts narration ("Extract the voice over narration for me") → ElevenLabs TTS
4. **Edit in CapCut:** strip baked audio, add SFX + music, sync VO

### [[Viral Style Repurposing]] (Bonus)
- Prompt Claude to swap 3D assets/elements to fit a NEW narration (~52 words per 30s), keeping the reference's visual DNA — same loop regenerates a new video

### Operating Wisdom
- "Consistency beats perfection" — ship regularly, improve per video

### Relevance
- Same toolchain as the Nepal motion-graphic experiment (Pexels + zoom effects in Premiere); AI path removes the After Effects barrier entirely
