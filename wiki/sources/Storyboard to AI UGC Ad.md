# Storyboard → AI UGC Ad — Flow Agent (Klever Nuts AI)

**Source:** YouTube video by [[Klever Nuts AI]], 2026-08-05
**URL:** https://www.youtube.com/watch?v=b0loy5hMFXs

## Summary

One storyboard + one prompt → [[Google Flow]] Agent auto-generates a complete 30s AI UGC ad (Medicube cream demo): TikTok-referenced copyright-safe character, persona-generator multi-angle shots, character ID sheet, A-roll/B-roll storyboard, agent-split clips, ElevenLabs voice-changer polish.

## Key Takeaways

### Prep (all in chat: Gemini/ChatGPT)
1. **Product:** Amazon best-seller beauty pick (Medicube cream) — proven demand
2. **Script:** hook-first, short/concise prompt output
3. **Character:** screenshot a TikTok UGC model you like → "describe her" → "create a Flow character prompt for a *similar* character" (avoids using a real person's face)
4. **Angles:** community *character persona generator* tool → ~6 shots (close-up etc.) → screenshot → **character ID sheet** (face definition from all angles)
5. **Background:** bedroom setup frame; **storyboard:** A-roll/B-roll with timeframes from the script

### Agent Assembly
- Paste product link + full script + constraints ("one consistent main character, name Sarah") into Flow Agent chat; @-tag character, voice, background, profile shots, storyboard; declare 30s total, let agent split into 5–10s clips → 4 clips in ~1 minute, VO included
- Regenerate bad frames by instruction ("redo frame 1, keep dialogue as background VO")

### Polish
- Light trim (Final Cut/CapCut); export MP3 → **ElevenLabs voice changer** for a more emotional, less-AI voice

### Business Note
- AI UGC ads = real paid business model; imperfections acceptable (unnatural phone hold) if the loop is fast
