# Claude Video — Teach Claude Any Skill from YouTube

**Source:** YouTube Short by [[Jack Roberts]] — [Watch](https://www.youtube.com/shorts/Rlfy0w4cIjY)

## Summary

Claude Video is a free tool that teaches Claude any skill by feeding it YouTube tutorials. Drop in a link to any tutorial — it grabs the transcript AND visuals, gives Claude full context of what's being discussed (instead of guessing from text alone), then asks Claude to create an entire workflow and save it as a reusable skill.

## Key Takeaways

- **YouTube → Claude skill:** Feed any YouTube tutorial link, Claude learns the skill
- **Transcript + visuals:** Grabs both text and video frames for full context
- **Full context, not guessing:** Claude sees what's actually being demonstrated
- **Save as skill:** Creates reusable workflow saved as a skill for future use
- **Free tool:** No cost to use
