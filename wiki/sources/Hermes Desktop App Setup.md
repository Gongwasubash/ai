# Hermes Desktop App Setup

Source: [YouTube](https://www.youtube.com/watch?v=oPASPLaYZCo) by [[Yashica Jain]]

## Summary

Hermes Agent now has a desktop app — no self-hosting required. It's a self-improving AI agent framework that learns from conversations and gets better over time. The desktop app makes it accessible to anyone.

## Key Points

- **Hermes is a framework, not an assistant** — it needs an AI model "brain" (OpenRouter recommended for pay-as-you-go access to hundreds of models)
- **Soul.md customization** — replace the default system prompt with your own persona/instructions
- **71 built-in skills** — PowerPoint, computer use, browser automation, file operations, cron jobs, etc.
- **Persistent memory** — the self-improving loop that makes Hermes remember and learn
- **Skills are extensible** — create custom skills for repetitive tasks

## Use Cases Demonstrated

1. **Computer Use** — organize files/folders by taking screenshots, moving files (found 21 screenshots and moved them)
2. **Browser Automation** — navigate, click, type, scroll (different from web search — can extract YouTube comments, competitor analysis)
3. **Cron Jobs** — scheduled automations (e.g., scrape Reddit every 3 days for Claude ecosystem updates, generate PDF reports)
4. **Sub-Agents** — spin up multiple agents for parallel work (e.g., pro vs con debate on SpaceX IPO)

## Setup Steps

1. Download from hermes-agent.nousresearch.com/desktop
2. Connect to OpenRouter (create account, add $5-10 credits, generate API key)
3. Change model to Claude Sonnet or similar
4. Customize Soul.md for your persona
5. Configure skills and tools
