## Summary

Lecture 1 of the Forward Deployed Engineering series: from absolute basics to GPT, first-principles style. Prereq = any one programming language. Series roadmap: Spring AI → APIs → RAG → Agents → Vector DBs. Next video: tokens/tokenization inside LLMs.

## Key Takeaways

### The Ladder
1. **Deterministic software** — predefined outputs (2+2 always 4), precisely defined instructions
2. **Rule-based AI fails language** — "I want to return my order" (angry vs polite) can't be rule-matched; natural language has no predefined outputs
3. **ML classification** — spam filter demo: show labeled data (spam vs not-spam), model learns the boundary; same pattern for support-ticket urgency
4. **Neural nets** — mimic brain neurons for problems humans can't write patterns for
5. **Prediction demo** — 3-line corpus ("I like ML/Java...") as the whole universe: model predicts next words from training distribution
6. **Transformers** — "Attention Is All You Need" changed NLP processing vs sequence/statistical approaches
7. **GPT** = Generative (generates language, unlike classifiers) + Pre-trained (huge datasets) + Transformers
