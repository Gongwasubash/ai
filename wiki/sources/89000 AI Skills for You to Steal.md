# 89,000 AI Skills for You to Steal

**Source:** YouTube Short by [[Jack Roberts]] — [Watch](https://www.youtube.com/shorts/h8e334CiG1M)

## Summary

Skill Retrieval MCP is a free search engine for AI skills — 89,000+ skills pulled from Anthropic's own guides and community contributions. Instead of stuffing all skills into a context window (impossible), the agent searches for the most relevant skill based on your request and pulls the full context on demand.

## Key Takeaways

- **Retrieve, don't build:** Stop writing skills from scratch when 89K already exist
- **Search engine pattern:** Agent searches relevant skills → pulls full context per request
- **Source:** Skills pulled from Anthropic guides + community contributions
- **Context window solution:** You can't fit 89K skills in context; retrieval solves this
