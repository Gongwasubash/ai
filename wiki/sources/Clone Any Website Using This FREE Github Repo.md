# Clone Any Website Using This FREE Github Repo

**Source:** YouTube Short by [[Jack Roberts]] — [Watch](https://www.youtube.com/shorts/e9DA7Epr2-M)

## Summary

A free GitHub repo that clones any website from a single screenshot. Drop in an image, pick your framework (React, Vue, HTML), and it generates the code. The real workflow: pick a landing page, edit it with ChatGPT image generation, drop the mockup into the repo — you get a pixel-perfect site with a design plan you can approve before any code is written.

## Key Takeaways

- **Screenshot → code:** One image produces React, Vue, or HTML output
- **Design-first workflow:** Use ChatGPT image to create a mockup, then clone that instead of hoping AI gets it right
- **Approve before code:** Beautiful design plan you can review before AI writes anything
- **Not just cloning:** Better use case is designing your own landing page first, then generating from the approved mockup
