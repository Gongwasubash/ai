# Antigravity Generative UI

YouTube video by [[AI with Surya]] demonstrating Antigravity's new generative UI feature — agents build live working apps and render them directly inside the chat interface.

## Key Takeaways

- **Generative UI** is a slash command in Antigravity that lets agents build and render live working apps inline in chat
- Not code for an app, not a screenshot — the actual running application renders in the conversation
- Powered by **Gemini 3.7 Flash** for fast generation

## Demos Shown

1. **Live Loan Calculator** — sliders for amount, rate, years; chart updates live as sliders drag (< 30 seconds)
2. **Animated Sorting Algorithm Race** — 5 algorithms sort colored bars side by side in real time with speed counter, deck size slider, restart button, and audio
3. **Interactive Project Code Graph** — reads a codebase and generates an interactive graph of project structure (main.py, models.py, solver, reporter) — under 60 seconds
4. **YouTube Channel as Living Galaxy** — reads channel video.csv, renders each video as a glowing star sized by views with physics animation, clickable for metadata, search box, play/pause

## Significance

- Demonstrates the shift from "AI writes code" to "AI builds and renders live apps"
- Each demo built from a single natural language prompt
- Shows generative UI as the next evolution of AI coding assistants
